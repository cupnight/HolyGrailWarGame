## 프레임 순서

마스터 1행: 대기 / 호흡 대기 / 놀람 / 손등의 령주 사용 / 다침 / 쓰러져 누움.

서번트 각 행의 왼쪽부터:

1. 대기 / 예비 동작 / 무기 치켜듦 / 타격 / 마무리 / 호흡 대기
2. 대기 / 피격 / 움찔 / 낮은 회피 / 방어 / 대기
3. 보구 자세 / 충전 / 최대 충전 / 해방 / 마무리 / 대기
4. 휘청 / 무릎 꿇음 / 쓰러지기 시작 / 쓰러짐 / 누움 / 누운 채 정지

manifest.json은 0부터 시작하는 프레임 번호와 테스트 재생 시간을 제공합니다.
x=(frame%6)*256, y=Math.floor(frame/6)*256 위치에서 256×256을 읽습니다.
재생 시간은 테스트용 제안이며 게임 연출에 맞춰 조절할 수 있습니다.
쓰러짐은 마지막 프레임을 유지합니다. 선택 사항인 5행은 없습니다.
적은 게임에서 좌우 반전합니다. 키 차이는 게임의 신장 배율로 처리합니다.
마스터는 지정된 성별만 제작되어 해당 유형의 성별 선택을 연결 시 맞춰야 합니다.

이 변경은 이미지와 배치 정보 추가이며, 게임 표시·재생 코드 연결은 별도입니다.
내장 image_gen으로 생성한 PNG이며 프레임 추출·크기·지면 정렬을 거쳤습니다.

랜슬롯 v3: 24개 프레임 모두 검을 계속 쥐도록 수정했습니다. 대기·회복·피격·쓰러짐 사이에서 검이 사라지지 않습니다.
