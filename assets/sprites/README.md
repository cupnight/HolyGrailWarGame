# 테스트 캐릭터 애니메이션 — 데포르메 유지 · 명암 강화

작업 가이드: https://claude.ai/artifact/TFCPss31cF7vH5PSeZW9tN

사용자가 확인한 최신 명암 강화 버전으로 기존 캐릭터 4종을 교체했습니다.
큰 머리와 짧은 팔다리의 기존 데포르메를 유지하면서 명암과 픽셀 표현을 다듬었습니다.
마스터는 머리카락·피부·옷감, 쿠 훌린은 전투복·은색 장식·붉은 창의 재질 구분을 강화했습니다.
랜슬롯은 뒤로 쓰러지는 흐름을 유지하고 쓰러짐의 명암을 다른 동작에 맞춘 v5입니다.

투명 RGBA PNG, 칸당 256×256, 6열, 칸 사이 여백 없음, 지면 y=240.
게임 루트 기준 주소: assets/sprites/파일이름.
쿠 훌린은 붉은 창, 랜슬롯은 검을 대기·공격·피격·보구·쓰러짐 전 과정에서 유지합니다.

## 프레임 순서

마스터 1행: 대기 / 호흡 대기 / 놀람 / 령주 사용 / 다침 / 쓰러져 누움.

서번트 각 행의 왼쪽부터:

1. 대기 / 준비 / 무기 치켜듦 / 타격 / 마무리 / 호흡 대기
2. 대기 / 피격 / 움찔 / 낮은 회피 / 방어 / 대기
3. 보구 자세 / 충전 / 최대 충전 / 해방 / 마무리 / 대기
4. 휘청 / 낮아짐 / 넘어짐 / 착지 / 누움 / 정지

랜슬롯은 뒤로 주저앉아 등이 바닥에 닿는 동작입니다. 마지막 두 칸은 동일한 누운 자세를 유지합니다.
쿠 훌린은 창을 쥔 채 낮아져 쓰러지고 마지막 누운 자세를 유지합니다.

manifest.json은 0부터 시작하는 프레임 번호와 테스트 재생 시간을 제공합니다.
x=(frame%6)*256, y=Math.floor(frame/6)*256 위치에서 256×256을 읽습니다.
재생 시간은 게임 연출에 맞춰 조절할 수 있습니다. 쓰러짐은 마지막 프레임을 유지합니다.
적은 좌우 반전하며 키 차이는 게임의 신장 배율로 처리합니다.
마스터는 지정된 성별만 제작되어 연결 시 해당 성별 선택에 맞춰야 합니다.
선택 사항인 서번트 5행은 포함하지 않았습니다.

내장 image_gen으로 자세별 그림을 생성하고 프레임 추출·크기·지면 정렬을 거쳤습니다.
이번 변경은 이미지와 동작 정보 교체이며 게임 표시·재생 코드 연결은 별도입니다.
